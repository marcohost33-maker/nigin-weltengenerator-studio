# Sicherheit

Die NIGIN-Spiele sind einzelne HTML-Dateien ohne Server und ohne Netzwerkzugriff.

Wenn du eine Sicherheitslücke findest, melde sie bitte **nicht** in einem öffentlichen Issue, sondern über
**[Private vulnerability reporting](https://github.com/marcohost33-maker/nigin-weltengenerator-studio/security/advisories/new)**.
Wir antworten so bald wie möglich.
